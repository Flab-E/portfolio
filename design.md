# Portfolio Design Style Guide

## Design Philosophy

### Color Palette
- **Primary**: Sophisticated greyscale (#1a1a1a, #2d2d2d, #4a4a4a, #f8f8f8, #ffffff)
- **Accent**: Minimal turquoise/sea green (#14b8a6, #0d9488, #0f766e)
- **Supporting**: Charcoal (#374151) and light grey (#9ca3af)

### Typography
- **Display Font**: "Canela" - Bold serif for headings and hero text
- **Body Font**: "Neue Haas Grotesk" - Clean sans-serif for readability
- **Code Font**: "JetBrains Mono" - For technical content and code snippets

### Visual Language
- **Minimalist Aesthetic**: Clean, uncluttered layouts with generous white space
- **Professional Tone**: Sophisticated and trustworthy, reflecting cybersecurity expertise
- **Technical Precision**: Sharp edges, geometric patterns, and structured layouts
- **Subtle Depth**: Layered shadows and subtle gradients for visual hierarchy

## Visual Effects

### Used Libraries
- **Anime.js**: Smooth animations for UI elements and transitions
- **Typed.js**: Typewriter effect for hero section text
- **Splitting.js**: Text animation effects for headings
- **ECharts.js**: Data visualization for skills and project metrics
- **p5.js**: Creative coding for background effects
- **Splide.js**: Image carousels for project galleries
- **Pixi.js**: Advanced visual effects for hero background

### Animation & Styling
- **Text Effects**: 
  - Typewriter animation for hero title
  - Character-by-character reveal for section headings
  - Subtle color cycling on accent elements
- **Background**: 
  - Animated network visualization using p5.js
  - Subtle particle system with greyscale particles
  - Turquoise accent nodes for key connection points
- **Interactive Elements**:
  - 3D tilt effects on project cards
  - Smooth hover transitions with depth shadows
  - Animated progress bars for skills visualization

### Header Effect
- **Hero Background**: Custom-generated cybersecurity network visualization
- **Text Treatment**: Large display font with subtle text shadow
- **Accent Elements**: Minimal turquoise highlights on key interactive areas

### Layout Principles
- **Grid System**: 12-column responsive grid with consistent spacing
- **Vertical Rhythm**: 24px baseline grid for consistent spacing
- **Responsive Design**: Mobile-first approach with breakpoints at 640px, 768px, 1024px
- **Content Hierarchy**: Clear visual hierarchy using typography scale and color contrast

### Interactive Components
- **Skills Matrix**: Animated grid with hover reveals and progress indicators
- **Project Gallery**: Filterable grid with smooth transitions
- **Timeline Navigator**: Interactive timeline with expandable content sections
- **Contact Form**: Real-time validation with smooth feedback animations
